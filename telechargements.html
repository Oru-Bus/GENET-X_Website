Guide d'installation

🎮 Installer GENET-X

  1. 1
    Téléchargez le fichier GENET-X.msi ci-dessus.
  2. 2
    Double-cliquez sur le fichier pour lancer l'assistant d'installation.
  3. 3
    Suivez les instructions à l'écran. Le jeu sera accessible depuis le menu Démarrer de Windows.
  4. 4
    Pour jouer en multijoueur, assurez-vous que les deux ordinateurs sont sur le même réseau local (Wi-Fi domestique ou Ethernet). L'un des joueurs lance un serveur, l'autre le détecte automatiquement.
  5. 5
    Pour désinstaller, utilisez l'outil de gestion des applications de Windows ou le fichier uninstall.exe généré dans le dossier d'installation.
⚠️
Si Windows affiche un avertissement de sécurité (SmartScreen), cliquez sur « Informations complémentaires » puis « Exécuter quand même ». Le jeu n'est pas signé numériquement — il est sûr.

Prérequis

Système d'exploitation
Windows 10 ou Windows 11 (64 bits). macOS non supporté pour la version joueur (le développement a été fait en cross-platform mais la distribution est Windows uniquement).

Réseau
Pour le multijoueur LAN : les deux joueurs doivent être connectés au même réseau local. Les réseaux d'entreprise avec pare-feux restrictifs peuvent nécessiter une configuration manuelle des ports. Consultez la page Connexion LAN pour plus de détails.

Python
Aucune installation de Python nécessaire — l'installateur .msi intègre l'interpréteur Python et toutes les bibliothèques requises (Pygame, PyTMX…).

Espace disque
Environ 300 Mo (jeu + dépendances + ressources multimédias).
